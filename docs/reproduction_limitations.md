# Reproduction limitations

Code paths are executable, but exact paper weights and numerical model results
cannot be recovered from the PDF. The practical landmark detector, tracker,
camera model, fuzzy secondary weights, score vector, and demo predictors are
explicit substitutes. Synthetic assets validate mechanics only. No claim about
student engagement, learning outcomes, fairness, privacy, or deployment fitness
should be made from smoke-test outputs.

Automated engagement inference is sensitive personal data. Real deployments
need informed consent, governance, bias/validity studies, human review, secure
retention, and a meaningful opt-out process.
